## 文件保护

- {{ORIGINAL_RULES}}加工这些原件时派生内容另存；工具会修改原件时使用真实副本，不通过链接改写原件。
- 按用户任务范围操作，不静默覆盖已有内容；删除和恢复须明确具体清单，整理不包含删除授权。
