# 项目目录协作规则

<!-- project-directory-organizer:rules:start -->
每次新建目录、创建、修改、复制、导出、整理或归档文件前，先读取并遵循[项目目录规则]({{RULES_FILE}})，按所属项目、用途与状态、关联、位置、命名依次分类。已有规则覆盖时直接执行，归属不明或规则冲突时先澄清；保护原件及必要配套，整目录移动也须核对后代用途，不能仅按后缀归类或混放同次运行的全部产物。

用户或适用规则已明确采用项目持续维护时，按约定的实际路径，在改动前复用或创建任务记录，完成后回填结果、验证与遗留事项，并更新本文件中真实、简短的当前进展和任务入口。纯只读操作不写记录，记录自身更新不递归创建记录；未采用时不额外创建维护目录或强加记录流程。保留已有项目介绍、约束及手写内容，遵守适用的全局规则，项目操作不顺带改写全局 AGENTS.md。
