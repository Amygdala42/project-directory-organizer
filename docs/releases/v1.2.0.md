# v1.2.0

本版保留必要的逐项提问，按任务提供较完整、可删减的候选框架，并把创建前分类用于后续每个文件。分类角色、实际目录名和命名格式分别处理，继续沿用原件、引用及操作范围保护。

## 行为与接口

- 新建时确认位置、操作、语言、用途及分别独立的代码、数据、分析、环境需求；相关未知项逐个确认，已明确不重复询问。具体目录名和层级可由助手在完整方案中推荐。
- 第一版在任务相关范围内覆盖较多环节，标记建议保留和可删减扩展；修改意见后重列完整计划。树内拟建项构成本版执行范围，待定建议单列；用户明确执行后才创建。
- 每次在项目中创建、复制、下载或导出文件，先确认归属、用途与状态、关联、位置和名称。已有规则充分时直接完成授权任务；缺项或需要扩展范围才补充确认，不逐文件写分类清单。
- AGENTS.md保留简短创建前入口，PROJECT_RULES.md持久化分类方法及实际目录用途，支持后续普通文件任务。工具原生位置与配套关系继续保留。
- 基础plan的layout增加可选rules列表，存放已确认的具体分类、命名或批次约定；最多500条、每条最多1000字符且为非空单行，拒绝控制字符及保留标记。省略时保留旧输入形状，不自动附加业务约定。
- 取消生成规则中未经选择的日期目录、v01和英文小写ASCII连字符要求；明确采用的格式仍可写入rules。原有plan/apply与增量登记接口保留，已有文稿不自动重写。保存计划绑定模板，升级后重新生成并核对计划。
- 复用现有技能文件和脚本，不新增分类数据库、配置文件或后台服务。技能指导助手操作，不自动拦截其他程序或监听手工创建。
