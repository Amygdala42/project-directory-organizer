# v1.0.1

本版完善逐项确认、计划与执行的衔接，新增多个独立子项目的规则增量维护，并修复文件操作失败时的记录处理。

## 交互与项目规则

- 每次只询问一个未确认事项；分析目录与独立环境分别确认，短回答只适用于当前问题。连续对话无需重复引用技能。
- 异步提问后保留当前回合等待实际回答，不因普通超时或子代理完成而结束等待；完整计划在正式回复中交付后，再等待对应的文字执行指令。
- 多个子项目分别登记路径、用途、环境、命名及成果规则；新增项目时增量维护总规则，保留旧项目文件、约定和已有子级规则。
- 明确示例中的分析及环境选择来自用户分别确认，不能由项目用途代答。

## 文件操作修复

- 移动的二次预检失败时，仅清理本次新建、身份未变且仍为空的日志；非空或被替换的日志保留，清理失败不掩盖原错误。
- 删除隔离区或批次初始化失败时保留现场，返回阶段、记录位置和未移动目标；预定清单位置不表示清单已成功写入。

## 验证

- Windows 回归测试共184项：183项通过，1项因符号链接权限不足跳过；包含6项新增故障回归测试。
- 临时目录实测覆盖一次新建3个不同用途项目、已有2个项目再批量新增2个，以及重复执行。旧项目文件和专属条款保持不变，重复执行未改变文件内容、修改时间或目录结构。
- 独立代理仅凭生成的项目规则，正确识别各项目的目录、配置、环境和成果命名；另有逐项问答与计划边界的文字检查。

验证不包含项目运行环境安装、业务程序运行或真实弹窗生命周期。技能不能设置应用未提供的弹窗显示时长，也不实现后台目录监听。

## 版本与兼容性

- 仓库VERSION、README、使用说明及技能metadata.version统一为1.0.1；技能名称与显示名称保持稳定。
- Python 3.9+，脚本仅依赖标准库；移动和删除的写操作继续仅支持Windows。
- 计划、清单与日志的schema_version保持原有格式版本；已有成功记录的恢复/回退接口不变。
- project_rules.py仍保留已有规则，布局只支持一个environment字段；多个项目的不同约定与增量合并由助手按技能维护，不把keep结果视为已完成同步。
