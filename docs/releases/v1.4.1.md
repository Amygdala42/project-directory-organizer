# v1.4.1 管理方式确认与审查修复

版本日期：2026-10-02（Asia/Shanghai）。

## 变更

- 多个独立项目的管理方式成为与目录语言同等的适用必答项：确认位置和操作后，先选择同一工作区统一管理或各自独立维护。已有明确覆盖目标的选择不重问；单项目及 src/docs 等功能目录跳过此题，未答不默认布局。
- 统一管理保留工作区主根登记；各自独立时，每个项目根维护完整 AGENTS.md 和 PROJECT_RULES.md，使用各自根的基础 plan/apply，环境与成果路径也相对各自根。操作说明及当前交互场景同步分流，不建立共同父目录登记。
- 修复移动回退日志的硬链接写入遗漏：回退规划、打开日志后和每次追加前检查日志链接数，拒绝多链接日志，避免连带修改其他位置。普通数据文件的硬链接移动与回退保持兼容。
- 修复项目登记对已有路径引用的识别：兼顾原始路径和本工具生成的 Markdown 转义形式，防止同一路径的新旧规则并存；保持路径身份、名称边界和明确 before 迁移的字节保留。
- 修复 Markdown 链接核对：正确处理链接文字中的代码格式、代码中的注释标记以及标签内跨行的代码或注释；代码与注释中的伪链接仍忽略，遮蔽内容不会把分隔片段拼接成链接。
- 精简全局职责与重复流程说明，全局 AGENTS.md 负责适用的通用工作流和护栏。保留用途与状态分类、完整项目规则、变更记录及状态归档要求。
- 增加相关回归，保持 20 个安装文件、现有 CLI 与 schema，不引入第三方运行依赖或后台监听。技能升级不自动改写旧项目。
