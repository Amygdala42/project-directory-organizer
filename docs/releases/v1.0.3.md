# v1.0.3

本版修复新增独立项目时，将主根或旧项目的约定当作新项目答案而跳过提问的问题。确认范围覆盖所有影响本次工作的选项和约束，不限于目录语言。

## 新项目逐项确认

- 新增独立项目重新检查语言、用途、分析目录、独立环境、成果位置、命名归档、共享资源及其他相关约束；旧项目的选择只作背景，不自动替新项目作答。
- 一次询问一个未确认事项，未回答不推进；不能把未确认约束预填进计划，再用计划获批替代前置问答。
- 仅复用用户明确覆盖当前目标或本次批量目标的答案。同一目标跨轮继续保留已答项，单个项目的答案不自动用于其他项目。
- 新选择与旧约束冲突时，先确认适用范围或处理方式，再把精确规则差异纳入完整计划；收到对应的执行指令后才写入。
- 语言差异检查限定本次目标及明确涉及的路径，不因新子项目选择不同语言而改名主根或同级旧项目。
- 已有项目的普通内容编辑及已登记位置内新增成果沿用其规则，不重启新建问卷。

## 文档与规则模板

- 技能入口、操作说明、多子项目说明、目录参考、示例、README及使用说明统一上述范围。
- 项目规则模板明确各项约定只适用于已明确列出的目录或已登记子项目；新增项目的选择和适用范围尚待确定。
- 补充主根约束、新项目逐项确认、批量答案范围、冲突处理及旧项目普通编辑的交互回归场景。

## 验证

- 独立代理先在v1.0.1副本上复现继承主根英文约定、跳过语言题的问题；修订后的六个连续问答点覆盖语言、分析、环境、成果位置、命名和共享资源。
- 三组边界演练覆盖批量项目答案范围、已有项目普通编辑及新选择与旧规则冲突。
- 发布前完整Windows回归测试共184项：183项通过，1项因符号链接权限不足跳过；维护目录与全局安装技能的全部16个文件逐一校验一致。

问答验证为文字演练，不包含真实弹窗生命周期；本版不增加程序化提问门禁。

## 版本与兼容性

- 仓库VERSION、README、使用说明及技能metadata.version统一为1.0.3；本地全局安装同步同一技能内容。
- 本次从v1.0.1直接发布v1.0.3；历史发布说明及问题复现记录保留当时版本，不补建v1.0.2。
- 技能名称、显示名称、Python运行要求和脚本接口保持稳定，计划及日志的schema_version继续使用各自的格式版本。
