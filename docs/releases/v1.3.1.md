# v1.3.1 按用途、状态与关联管理目录

版本日期：2026-10-02（Asia/Shanghai）。

## 变更

- 文件分类遵循“项目归属 → 用途与状态 → 关联 → 位置 → 命名”。扩展名辅助识别内容，不设置通用格式白名单，也不将所有文件按后缀拆分。
- 所有目录的规则都要明确主要内容、必要配套、应另存内容及其去向。报告、图片、代码工程、数据、资料、工作草稿和运行记录均按真实用途划分边界。
- 报告可以是 Markdown 或 HTML；阅读说明、必要配图和明确随报告交付的附件可与报告保存。生成器、内部草稿、运行配置、中间数据、缓存和日志另按真实用途存放。“同次生成”或笼统的“相关”不足以证明应放在一起。
- 配套关系要能说明其服务对象：工程所需的 `config.json`、README 和素材保留在工程内；字段说明可随数据保存。CSV、JSON 或 README 的位置取决于其实际角色，不仅取决于名称和格式。
- 混合格式本身不要求新建 `deliverables/`。确需独立打包时才规划交付位置，保留必要依赖和维护源关系；普通报告阅读资源可随报告保存。
- 同时覆盖新建与整理：新建或批量生成前安排角色与位置；整理核对每条映射及整目录全部后代的用途、状态和关联；执行后复核实际内容与配套完整性，并报告保留项和未核实项。方案、清单和日志也按自身用途归类。
- 已有明确项目约定优先，冲突时提出与本次任务相关的精确差异；不因版本升级自动改写旧规则、迁移历史文件或拆散工程。
- 同步更新技能入口、参考说明、模板、生成文字和使用文档。布局与检查器接口保持兼容，本版没有新增语义检查器、后台监听或自动写入拦截。

## 验证

- 在 Windows、Python 3.11.15 运行 `python -B -X utf8 -m unittest discover -s tests -p 'test_*.py' -v`：共269项，268通过、1跳过，无失败或错误。唯一跳过项为 `test_safe_delete.SafeDeleteTests.test_file_symlink_is_not_followed`，原因是创建符号链接夹具返回 WinError 1314 权限不足；不将其计为通过。
- 在系统临时项目实际执行基础 `plan/apply`：计划阶段未写入文件，首次执行仅创建 `AGENTS.md` 和 `PROJECT_RULES.md`；重复计划全部为 `keep`，重复执行后文件字节不变。未操作实际业务文件。
- 独立代理仅依据实际生成的两份规则完成五组文字演练，正确处理 Markdown 报告与诊断记录、PDF 图表、XLSX 日志、工程配置与素材、数据说明、真实交付附件、工具混合输出暂存，以及整目录整理。文字演练没有执行真实文件迁移，脚本回归也不等同于语义分类能力。场景及结果见[交互回归](../../tests/interaction-scenarios.md#v131-按用途状态与关联管理目录)。
- 对最终技能、参考说明、模板、生成文字和使用文档的独立复核未发现实质问题；原有项目专属格式约定没有被误改成通用白名单。
- 67个本地文档链接、15个章节锚点、8个 JSON 示例有效；6个脚本通过 Python 3.9 语法解析检查。语法检查不代表在 Python 3.9 上运行过回归。`git diff --check` 通过。
- 维护技能和已安装技能均通过 `quick_validate`；安装副本同步后，全部19个文件的相对路径及 SHA-256 与维护源完全一致。
