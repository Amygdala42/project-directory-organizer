# v1.1.0

本版根据参考技能包的设计分析，补齐只读检查、摘要和规则维护能力。沿用现有移动、删除、恢复实现，没有复制参考包的执行引擎。

## 新增能力

- `folder_inventory.py --summary --top N`：按直接子目录、扩展名、修改时间汇总，输出最大/最近修改文件的完整相对路径。以扫描完成时间划分时间区间，未来和未知时间单列，保留遗漏和错误；默认完整盘点JSON保持兼容。
- `directory_verify.py ROOT --policy-file FILE|-`：对显式已确认的路径、命名例外、Markdown规则入口链接和项目归属作只读检查。计划未建、实际偏差与无法判断分开；业务用途、自由条款及实际环境安装状态不伪装为通过。仅指定链接源允许限额读取正文，其余使用元数据。
- `project_rules.py update-plan ROOT --projects-file FILE|-`：使用稳定项目id及已确认记录生成schema 3增量计划。局部管理段保存正文SHA-256，精确迁移旧段或显式初始化，保护其他项目和手写字节；人工改动、损坏标记和并发变化阻止自动写入。旧schema 2及apply命令兼容。
- 增加内容创作、项目交付、资料库的可裁剪规划范例；不强制目录数量、编号、日期、环境或报告目录。

## 范围与兼容性

- 所有新只读命令默认只输出到标准输出，不自行保存plan.json、策略或缓存，不自动修复偏差。
- 不增加扩展名默认白名单，不把同内容文件自动去重，不调整现有移动日志和隔离恢复协议。
- 目录语言与文档正文语言分别处理，原件、工具原生结构、独立子项目选择和跨日批次规则沿用。
- 增量更新不能可靠解析任意手写登记表；复杂旧文档需人工精确迁移，不自动覆盖全文。写入不是断电安全事务，失败时依据started_writes核查。
- 当前版本声明同步为1.1.0，历史发布说明保留原版本。
